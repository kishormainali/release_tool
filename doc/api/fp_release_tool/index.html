fp_release_tool

fp_release_tool library

A centralized CLI tool to streamline Flutter releases on Android and iOS using Fastlane.

This package provides the release_tool executable for your terminal. While it is primarily intended to be used as a command-line interface, it exports the core configuration models for programmatic access.
